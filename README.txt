Reds QOL 1.0.3

Left-click minimap / /rqol: settings.
Right-click minimap: unlock or lock QOL displays only (Campfire, Top Bar, Range).
Click Lock position to finish. All mover highlights use brown and amber.

Blizzard windows such as spellbook and talents can be dragged normally, outside
QOL placement mode. Use their title bars or bare window areas. Settings in Move
Frames offer optional Shift-to-drag, Ctrl+wheel resizing, and window reset.
This does not add Blizzard HUD overlays or hook Blizzard/Ellesmere edit modes.

Reload after updating. Original RedsUI and standalone Campfire files are kept.

1.0.4: A movable, one-click Reload UI button is enabled by default. Reposition it using the QOL unlock control. Show or hide it on Move frames.
This release is published through AyoRed/RedsUI on GitHub.
